# Tyldesley Jewellers — website preview

Custom jewellery by Caitlin Tyldesley, Cape Town. Static site (HTML/CSS/JS, no build step):
a procedural Three.js ring, a pinned scroll story (sketch → watercolour → blueprint → wax → cast → set → polish),
a ring configurator that sends the idea to Caitlin, collections, Buy a Design, remakes, engraving and the shop.

Preview only: `noindex` + `robots.txt` keep it out of search engines until it goes live on tyldesleyjewellers.com.
